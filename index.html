Build clean layouts with Flexbox and Grid

This homepage uses Flexbox for the navigation and CSS Grid for the main content. Resize the window to see it switch between one, two and three columns.

Flexible navigation

The header is a flex container. The logo and links are pushed apart with justify-content.

Grid content

Cards sit in equal columns. The gap property handles all the spacing.

Two breakpoints

One column on phones, two on tablets (700px and up) and three on desktop (1024px and up).

About this page

This wide card spans every column. All colors, the radius and the spacing come from CSS variables defined once on :root, and dark mode follows your system setting.
